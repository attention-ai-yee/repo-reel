# V2 成片质量流程

## 结论

V1 的失败不是 FFmpeg 参数不够好，而是把内容制作压缩成了“JSON → 一张卡片 → 系统朗读”。V2 把三个问题拆开治理：

1. **编辑：**先写口语稿和观点，再做画面；
2. **声音：**先用 10–15 秒盲听门选择声线，再生成整条；
3. **镜头：**真实产品证据为主，品牌包装只负责节奏和识别。

## 技术栈选择

- **主渲染：Remotion 4.0.489。**适合固定栏目视觉、参数化数据、React 动效、字幕和每周自动渲染。个人、非营利和不超过 3 人的营利组织可按其当前许可免费使用；更大组织需要商业许可。
- **后处理：FFmpeg。**负责响度、限幅、编码和完整解码检查。
- **OpenMontage：只借制作方法。**参考片拆解、脚本/分镜审批、素材表和成片 QA 值得采用，但其完整系统对这个固定栏目过重，最终合成本身仍会落到 Remotion 等工具。
- **MIT 备选：Revideo。**若以后不接受 Remotion 许可，可迁移到 Revideo；当前生态和模板成熟度略弱。

## V2 样段的变化

- 41 秒，只做开场、第 10 名和第 9 名；
- 使用 Impeccable 项目自己的 before/after；
- 使用 Herdr 项目自己的真实产品视频；
- 每 1.5–3 秒出现有效视觉变化；
- 去掉作者头像、总 Star 卡、相对速度等低价值重复信息；
- 统计口径压缩为 1.8 秒，不占黄金开头；
- 字幕按呼吸短句显示，透明底、描边、关键词着色；
- 文案改成“具体麻烦 → 怎么解决 → 主播判断”，不再逐项复述 README。

## 语音路线

当前 V2 使用用户指定的女声 A：`zh-CN-XiaoxiaoNeural`。它调用 Microsoft Edge 在线语音服务，不需要 API key，但仍不应作为最终账号声线。

正式流程的声音门：

1. 用户提供 10–20 秒干净、自有、无背景音乐的参考录音及准确文字；
2. 同一段文案生成 GPT-SoVITS CPU、VoxCPM1.5 本地、Edge 基准；
3. 若接受云服务，再加入 MiniMax Speech HD；
4. 盲听只评“像不像真人、停顿、英文项目名、是否客服腔”；
5. 未通过 15 秒盲听，不生成完整 3 分钟。

不建议使用 Kokoro 中文声线：其官方普通话音色质量评级不适合作为本次机械感问题的解决方案。CosyVoice 与 IndexTTS 能力强，但当前机器没有 NVIDIA CUDA，不是首选落地路径。

## 正式周更的制作门

1. **选题门：**数据口径、异常增星、项目是否值得讲；
2. **脚本门：**开头 8 秒、每项判断、重复句式检查；
3. **证据门：**每个项目至少一段真实界面、终端结果或 README 证据；
4. **声音门：**15 秒盲听通过；
5. **风格样段门：**只渲染开场和两个项目；
6. **全片门：**样段通过后才扩展 Top 10；
7. **QA 门：**字幕越界、黑帧、解码、响度、路线图能力标注和素材来源。

## 运行 V2 样段

```powershell
powershell -ExecutionPolicy Bypass -File scripts/render_v2.ps1
```

已有依赖和素材时：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/render_v2.ps1 -SkipInstall -SkipVoice -SkipAssets
```
